# Campus Night — Choose Your Own Adventure

A small browser choose-your-own-adventure built for **Global Hack Week: Hacktoberfest**.

GitHub Copilot (and Cursor) helped scaffold the scenes, CSS, and branching logic. This is the simple application for the *Use GitHub Copilot to Build a Simple Application* challenge.

## Run

Open `index.html` in a browser.

## Challenge notes

- **What it is:** a four-path campus story with restart.
- **Stack:** HTML, CSS, JavaScript (no build step).
